 Менеджер паролей

Учебный менеджер паролей на C++ с графическим интерфейсом Qt.  
Хранит пароли в зашифрованном виде (AES-256 CBC) в базе данных SQLite.  
Доступ к приложению защищён мастер-паролем.

 Основные возможности
Создание и проверка мастер-пароля
Добавление, редактирование и удаление записей (ресурс, URL, логин, пароль)
Копирование пароля в буфер обмена
Открытие URL в браузере
Все пароли шифруются ключом, производным от мастер-пароля (SHA-256)

 Сборка
1. Открыть PasswordManager.pro в Qt Creator.
2. Настроить комплект (Kit) с компилятором MinGW 64-bit.
3. Выполнить Build, Rebuild All (Или Rebuild Password Manager).
4. Для запуска без Qt Creator скопировать необходимые библиотеки с помощью windeployqt (Через cmd внутри папки debug).
5. Приложение создаст базу данных в папке %APPDATA%/PasswordManager/passwords.db (Хранит мастер пароль и все пароли).

 Структура проекта
Aes/ – библиотека tiny-AES-c (файлы aes.h, aes.cpp)
main.cpp. – точка входа, создание базы и диалога входа
mainwindow. – главное окно со списком записей
databasemanager. – работа с SQLite и шифрование
logindialog. – диалог ввода мастер-пароля
accountdialog. – диалог добавления/редактирования записи
