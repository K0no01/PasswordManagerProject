 Менеджер паролей

Менеджер паролей на C++ с графическим интерфейсом Qt,
хранит пароли в зашифрованном виде (AES-256 CBC) в базе данных SQLite,
доступ к приложению защищён мастер-паролем.

 Основные возможности
1. Создание и проверка мастер-пароля
2. Добавление, редактирование и удаление записей (ресурс, URL, логин, пароль)
3. Копирование пароля в буфер обмена
4. Открытие URL в браузере
5 .Все пароли шифруются ключом, производным от мастер-пароля (SHA-256)

 Сборка
1. Открыть PasswordManager.pro в Qt Creator.
2. Настроить комплект (Kit) с компилятором MinGW 64-bit.
3. Выполнить Build, Rebuild All (Или Rebuild Password Manager).
4. Для запуска без Qt Creator скопировать необходимые библиотеки с помощью windeployqt (Через cmd внутри папки debug).
5. Приложение создаст базу данных в папке %APPDATA%/PasswordManager/passwords.db (Хранит мастер пароль и все пароли).

 Структура проекта
1. Aes/ – библиотека tiny-AES-c (файлы aes.h, aes.cpp)
2. main.cpp. – точка входа, создание базы и диалога входа
3. mainwindow. – главное окно со списком записей
4. databasemanager. – работа с SQLite и шифрование
5. logindialog. – диалог ввода мастер-пароля
6. accountdialog. – диалог добавления/редактирования записи
